# RC40：报告样式第一版

2026-10-19。基于RC39，仅更新报告HTML渲染与CSS，不修改聊天前端、模型提示、查询、计算、引用或会话逻辑。

- 独立app/agent/report.css随核心镜像打包，并内联进保存的HTML；无外部字体/CDN/脚本依赖。
- 白底深蓝标题、青绿色分隔、深色表头及隔行底色，数值右对齐，窄屏自适应。
- 支持粗体、代码、列表、引用及层级标题；去除与报告标题完全相同的首个正文标题，原始HTML只按文本显示。
- PDF采用命名A4页面、独立打印尺寸、边距、重复表头和页码。保留源数值文本，不重新计算或缩短小数。

- 样例位于本地私有data/business_acceptance/report-style-preview-20261019/；本地预览HTTP端口8093。报告本身原有表述保留，未自动替换业务来源名称或补写结论。
- 已重建并更新核心容器为RC40，沿用原数据卷；RC39冻结镜像标签及归档保留。旧报告文件不自动重写，新生成报告采用新样式。

本版本为第一轮视觉优化，供用户确认效果；不将RC39模型验收记成RC40已完成同样的全量验收。
