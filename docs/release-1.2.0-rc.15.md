# RC15：附件非业务行告警分级

问题原因：所有 NONBUSINESS_ROWS 普通告警都被附件策略视为严重告警，已识别的底部备注也触发确认弹窗。

修复：仅当全部排除行为 note/repeated_header、原始值存在且源行分类一致时，服务端标记 auto_confirm_safe=true，允许自动导入。备注及重复表头仍完整留痕，不计入业务明细。汇总行、未知分类、旧草稿无安全标记的告警仍要求确认；覆盖错误、缺失公式缓存等规则不变。

验证：新增普通留痕自动确认、未知标记不放行及 API 自动导入回归；完整 Linux 测试 273 项，272 通过、1 跳过。数字门禁_v1.2_2025.xlsx 重新解析及验证：errors=[]、severe_warnings=[]，保留一条普通备注提示。无真实模型调用。

旧草稿的告警未迁移，需重新上传以按新规则验证；现有会话及业务数据保留。
