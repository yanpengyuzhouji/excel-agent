## 执行链

生产ExcelLLM启用evidence_publication，不启用旧analysis_contract。可先inspect/query，再调用计算工具（若需要），最后用result中的缓存引用发布。无需define_analysis、逐任务source/unit声明和bindings；无独立explanation逃逸通道。旧显式analysis_contract调用作为兼容路径保留，不是生产默认。

标量引用{{result-1:0:column|4}}和{{aggregate-1:0:difference|2}}；整表引用{{table:result-1}}、{{table:inspection-1}}。仅解析真实缓存坐标、舍入和转义，不再次计数/平均。缓存表格内容不能注入另一个引用。存在工具证据却完全不引用的发布被拒绝，不能直接用无引用解释替代查询结果。没有任意自然语言数字扫描，不宣称引用机制能证明模型所有文字或SQL语义。

html_interpreter使用result模板；报告请求也可直接terminate，程序从同一发布结果保存报告并返回文字和实际PDF链接，不再要求模型另生成HTML或再次终止。来源、SQL条件、去重和指标覆盖仍由模型解释，需独立验收。

工具返回result_kind、column_units、query_tables。已知SQL表达式提供单位提示，无法证明的血缘保持空，不阻断发布、不猜换算因子。完整结果保留在缓存，执行状态索引去除完整计算行，每轮只保留最新状态，历史证据可按ID分页读取。publication引用清单随回答持久化。
