# 1.2.0-rc.6

继承[RC5模型模式对齐](release-1.2.0-rc.5.md)。补充修复多工作簿/通用问答SSE收尾竞态：
在发出done/error之前先持久化上下文和预算、释放本次Agent名额；断开连接时由同一个
幂等收尾函数兜底。防止客户端收到完成后立即追问或删除时仍被上一轮占用阻止。
新增回归在终止事件序列化瞬间检查预算和名额均已收尾，而非等待HTTP响应结束才检查。

黄金回归脚本完整消费SSE至EOF，不在done处主动断连；不自动重发失败问题。
发布镜像：`excel-workbook-service:1.2.0-rc.6`。最终验收必须核对同一实际镜像摘要，
不得以RC1至RC5的通过项目替代本版完整回归。
