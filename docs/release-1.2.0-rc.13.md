# RC13：计算工具与数值引用门禁

本次修复 RC8 验收中“SQL 分组数据正确，模型最终自行加总错误”的缺陷。

- 复用 aggregate_results，sum 改为受限精确十进制；新增 difference、growth_rate，操作数必须引用缓存结果单元格，不接受模型填写的数值。
- 定量答案/HTML 可见数值要求绑定结果 ID、原始行号、列名，由服务端校验并填值；拒绝原始字段冒充总额、错误类型或越界引用、截断证据及缺少所请求的指标。NULL/零基数不作为零增长。
- 已校验答案不再二次调用模型重写。非定量草稿若进入最终润色，缓冲校验后才发布，防止错误数字先流出。
- numeric.validated 事件持久化，保留引用坐标、来源/输入结果 ID；默认日志仅记录状态与原因类别。
- 修复来源文件名、单位、真实查询覆盖表数、版本、NULL/精度/规格注释的非指标误判，不按任意数值相等放行。

协议与限制见 [数值证据协议](numeric-evidence-contract.md)。不引入新依赖，不开放内部元数据 SQL 或任意代码执行。
