# RC29：通用统计工具与额度备用

状态：模型回归因供应商计费错误中断，未生产放行；后续诊断见 [RC30记录](release-1.2.0-rc.30.md)。

## 变更及边界

1. 新增 `profile_workbook(workbook_id, table_name, columns)`：只接受授权物理列，最多12列，沿用只读SQL与资源预算。返回总行数、NULL数、空白字符串数、非空记录数。零不当空值，缺失与空白分开，结果保存在正常result-N缓存，支持引用与历史恢复。
2. 新增 `aggregate_results(operation=compare_totals, result_ids, baseline_column, current_column)`：先精确累加所有缓存行的两期值，再计算差额和增长率，返回同一行。拒绝截断和歧义列；NULL保留缺失，零基期保留未定义增长率，负基期不改成绝对值。模型仍负责选择正确来源/指标，不按问题关键词强行选口径。
3. 修复新运算结果被当成原始文本、不能设置小数位的类型登记遗漏，已加入Agent整体链路回归。
4. 按用户要求加入 `kimi-k3-bailian` 配置，复用现有百炼凭证；仅发生额度错误时切换，调用可用性待实际验证。不以换模型替换普通错误题分数，默认模型不变。
