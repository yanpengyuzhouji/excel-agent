# 1.2.0-rc.2

继承[RC1服务边界与验收协议](release-1.2.0-rc.1.md)，使用固定镜像标签
`excel-workbook-service:1.2.0-rc.2`。以最终实际image ID及验收记录为准。

RC1的完整64题结果原样保留，未作为RC2通过证明。RC2增加：

- 在无正文的首正文超时时，允许用新SDK连接恢复一次；不能复用正被关闭的连接。
- 两次尝试共享原总时限，并计入Agent调用及token估算预算；有部分输出不重放。
- 每次首正文阈值仍为10秒，因此恢复路径最多可能等待两次10秒；不承诺总等待10秒。
- 未明确要求舍入时，保留原始合计精度；展示近似值同时给出原始合计。
- 整体跨区域/年份比较先给整体合计、差额、增长率，不用分组明细替代整体结果。
- 窄范围单位校验保留“不是某单位”等否定说明，避免修正正确的解释文本。

最终交付证据置于私有`data/business_acceptance/release-1.2.0-rc.2`及所引用的运行目录。
