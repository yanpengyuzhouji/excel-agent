# 黄金测试集第一版

私有交付目录：`data/business_acceptance/gold-v1/`。真实源文件和业务标签已被 Git 与 Docker 构建上下文排除。核心服务不会自动加载这个目录，不影响现有会话。

包含 `files/` 冻结源文件、`gold.json` 固定预期和问答题，以及 `latest-results.json` 回归结果。每个源文件记录 SHA-256，每次执行先检查文件完整性；标签文件的 SHA-256 记录在执行报告中。不能用最新解析结果覆盖预期来消除失败。

## 范围

| 类型 | 数量 | 内容 |
|---|---|---|
| 正向工作表/区域 | 19 | 接地电缆推荐 1、导线库 1、国网批次 1、月度报表 13 个区域、扫描/重复统计的 3 个分区 |
| 格式拒绝 | 4 | 两个 XLS、两个 WPS ET，要求明确拒绝不支持格式 |
| 问答题 | 37 | 各区域有效记录数、原列数值合计，包含固定答案、容差和来源范围 |

这些是工作表/区域案例，并不代表 19 个完整工作簿全部可导入。每个源工作簿的整体门禁结果另列 whole_workbook_admission；只验证其中一张表通过不能推断全文件通过。

## 标准答案来源

`scripts/build_gold_v1.py` 直接读取原始 XLSX ZIP/XML、共享字符串和原始数值，用 Decimal 计算固定区间内的记录数与合计。生成标签过程不导入项目解析器、SQLite 建库器或 Agent。各工作表取数范围经过源文件内容检查后写入生成脚本，不通过待测解析器猜测表头。

记录判定：月度区域表以 E 列项目名称非空为有效记录，投资按对应 H 列原值合计，单位万元；国网批次按 A 列数字序号统计；其他案例以指定区域的关键列非空统计。月度报表不叠加“汇总”表，也不宣称已经按项目唯一键去重。其他合计按原列单位，不自动换算。数值容差 0.000001，数量及源行集合要求完全一致。

本版审核状态为 `independently_computed_pending_business_signoff`，human_reviewer 为空：已独立计算，尚未经过业务人员签字。应由业务人员核实取数区间、项目判定与统计口径，再记录审核人及日期。源文件中存在不确定口径时，修订到新版本并保留旧版。

## 执行

项目目录 PowerShell：

```powershell
$env:PYTHONIOENCODING='utf-8'
.venv/Scripts/python.exe scripts/run_gold.py --root data/business_acceptance/gold-v1
```

脚本按静态标签比对源行覆盖、解析后 Decimal 合计，再为被标注的工作表建立临时 SQLite，检查 COUNT 和 SUM；临时库运行结束清理。无需启动 8090 服务，不访问 Docker 中的业务数据，不调用模型。结果写入私有 latest-results.json，有任一失败则退出码为 1。生成脚本仅用于追溯构建，已存在 gold.json 时拒绝覆盖。

37 道问答题目前是模型验收题库，execution_status=not_run。解析/SQL 成功不等于模型已通过。业务人员可在测试页面逐题选择对应源附件，按题中指定工作表/区域核对数值、来源和单位；测试调用外部模型前需确认业务资料可发送给该供应商。自动模型评分、报告视觉质量、跨工作簿关联、并发、灾难恢复均不计入本次通过率。

## 后续扩展

首轮执行：23 个案例中 22 个通过，1 个失败（95.65%）。19 个正向区域中 18 个通过，4 个格式拒绝案例均通过。19 个正向案例的源数值还通过了另一套 openpyxl 读取方式交叉核对；这仍不替代业务人员对统计口径的复核。

失败 G001：接地电缆截面推荐表 Sheet1 的表头在第 3–4 行，真实数据为第 5–17 行共 13 条；当前解析选择第 5 行作为表头，从第 6 行开始读，漏掉 A5=160、B5=1*35。整体门禁也报告 UNCLASSIFIED_SOURCE_REGION。该缺陷保留为失败基线，本次制作数据集没有修改解析器或更新 Docker。

此外，导线库所在完整塔型规划工作簿有其他复杂工作表被阻断；其导线库单表通过不代表整份附件能直接导入。两个扫描报告完整文件无门禁告警，采购目录/月度报表存在需按业务处理的原始告警。准确状态见 latest-results.json 的 whole_workbook_admission。

增加多层表头、标识符前导零、公式缓存、隐藏行、空值与零值、跨表关联时，优先选择能够明确给出原坐标和业务定义的真实样本。每个新增案例记录正确结果和允许的告警状态；有歧义的数据先进入待审核集，不混入已审核集。人工复核后再将本版升级为正式发布验收基线。
