# RC17 定向修复与验证

日期：2026-10-16。已部署 `1.2.0-rc.17`，默认 DeepSeek；未改动业务数据卷、超时参数、并发上限。此次为定向回归，不是新一轮全部 100 题生产放行。

## 修复

- 带引用的快速回答与缓冲回答都应用已有加权单位契约，修复早返回漏掉单位处理。
- 新增 Decimal `ratio` 运算，明确分子/分母引用，返回倍数和百分比；与增长率分离。零分母返回 NULL，拒绝截断数据和字面量输入。
- 明确问题仅请求一个场景时，核对显式引用所在行的场景标签；沿派生运算追溯操作数。不对普通数字全文扫描，原文读取不强加计算门禁。
- 最终回答在缓冲发布前检查引用；失败可在原预算内纠正一次，不重新执行 SQL。再次失败仍报错，不输出无效引用。
- 针对多表目录中的“唯一工作表”正向断言增加窄范围检查；提示词要求区分核查范围，不以单表核查冒充全工作簿核查。
- 结构化控制响应纯空白时，已有的有界重试增加 JSON 格式提醒；不增加重试次数或延长截止时间。
- 计算结果引用未指定小数位且小数过长时，默认最多 12 位 HALF_UP 显示；缓存原值不变，原始文本及带前导零编号不变。
- 修正 A08 评分器把说明中的 `基期=0` 误当第二个差额；C19 评分仅增加带否定保护的“等于”同义表达，不改变原始历史结果。
- 定向测试允许选择完整连续会话，缺少任何一轮则拒绝，不能拆开 T01–T03 伪造上下文。
