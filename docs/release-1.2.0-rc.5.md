# 1.2.0-rc.5

继承[RC4空白正文修复](release-1.2.0-rc.4.md)。RC4真实回归发现同一控制步骤即使
恢复一次仍可能只返回推理和空格；不继续增加重试或把私有推理当工具指令执行。

DeepSeek的JSON工具控制步骤显式发送`thinking.type=disabled`，仍由模型判断工具与参数，
后端仍严格校验白名单。最终回答及普通聊天不改变思考配置，其他供应商不注入此参数。
这是对本项目控制协议的兼容选择，不宣称模型供应商永不空输出。
参数依据：[DeepSeek思考模式说明](https://api-docs.deepseek.com/guides/thinking_mode/)。

交付镜像：`excel-workbook-service:1.2.0-rc.5`，以实际验收摘要和导出包SHA256为准。
需完成本镜像两轮完整64题、报告视觉复核及独立容量/恢复验收后才可判定服务技术验收。
业务签字、Spring Boot权限及24小时以上持续运行仍单独验收。
