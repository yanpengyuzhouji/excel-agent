# 1.2.0-rc.8

继承[RC7字段与门禁修复](release-1.2.0-rc.7.md)。修复JSON工具协议的参数丢失：
模型将sql等已知参数放在action同层或与action_input混用时，解析器不再静默丢弃。
仅归一已知工具字段；若顶层与嵌套值冲突，则拒绝并要求模型纠正。
动作白名单、只读SQL校验、授权附件范围及预算门禁不变，不补写SQL或推测参数值。

日志`tool_envelope_normalized`只记录动作名和归一字段名，不包含SQL、参数值或推理内容。
旧候选失败缺少原始模型回复，不能反向断言所有漏参失败均由此原因造成；
新版本完整回归须分别保留工具归一、供应商请求及最终答案结果。

镜像：`excel-workbook-service:1.2.0-rc.8`，按实际镜像摘要验收和分发。

最终[服务验收结果](service-release-acceptance.md)：完整运行两轮64题及独立运维验收，
但仍有一次派生计算错误和一次上游连接失败，未通过发布门禁，不标记正式生产版。
