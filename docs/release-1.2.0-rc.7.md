# 1.2.0-rc.7

继承[RC6收尾竞态修复](release-1.2.0-rc.6.md)，补齐真实64题暴露的上下文与门禁缺陷：

- 目录超长时优先省略字段标签/样本，而非截掉第9列以后的物理字段；保留表映射和字段名。
  命名字段不可见时必须定向inspect，不得用工程名称等代理字段替代用户要求的分类列。
- 用户明确指定“某列非空”的物理记录口径，不强制套业务实体计数门禁。
  “自行”等普通词中的单个“行”字不再触发业务计数核验。
- 未完成业务计数核验时，终止拦截最多三次，不再反复提醒直到耗尽Token预算。
  真正的采购批次/业务记录问题仍保留计数核验要求。

发布镜像：`excel-workbook-service:1.2.0-rc.7`。最终验收以本镜像独立完整结果为准。
