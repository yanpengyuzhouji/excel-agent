# 数值计算与答案引用协议

## 当前策略（RC14）

RC16增量：新增加权平均Decimal工具、具名基期/本期参数；明确精度要求的差额及加权问题采用限定范围计算路由，必须完成并引用对应计算结果。普通数字和原文仍不扫描、不强制引用。见[RC16记录](release-1.2.0-rc.16.md)。

以下原 RC13 强制发布门禁描述仅供历史参考，RC14 以本节为准。
计算仍应调用 SQL/Decimal 工具，但不再扫描全文数字、强制所有数字附带引用，或根据关键词阻断回答。
可选引用只校验格式、结果 ID、行列边界与舍入类型；保留原始文本及编号前导零。
`numeric.validated` 仅表示引用解析成功，`numeric.observed` 为非阻断观察，不保证数字、单位与业务口径正确。
无效引用错误码为 `result_reference_invalid`；普通数字与缺失数据说明不会触发补算循环。
详见 [RC14 变更](release-1.2.0-rc.14.md)。

## RC13 历史协议（以下强制数字门禁已取消）

## 执行链路

授权工作簿版本快照 → 只读 SQL 查询 → 精确十进制汇总/比较 → 模型组织带结果坐标的文案或 HTML → 服务端核验并填值 → 发布。

计算能力复用 `aggregate_results`，没有新增外部计算依赖或任意代码执行能力。每次调用仍受 Agent 总工具次数、时间及上下文预算约束。

## 工具参数

```json
{"operation":"sum","result_ids":["result-1"],"group_by":["year"],"value_column":"amount"}
```

汇总保留 `computed_columns`，数值以十进制字符串返回，避免 JSON 再转换成二进制浮点数。NULL、非数字、NaN、无穷、截断输入及超过支持精度的加减被拒绝，不把缺失值默认为零。需要将无数据年份视为零时，应在有明确口径的 SQL 中使用 `COALESCE` 或 `CASE ... ELSE 0`。

```json
{"operation":"growth_rate","operands":[
  {"result_id":"aggregate-1","row":0,"column":"amount"},
  {"result_id":"aggregate-1","row":1,"column":"amount"}
]}
```

`operands` 固定为 `[baseline,current]`，只能引用缓存结果单元格，不接受模型填写的字面量操作数。`difference` 返回 `current-baseline`；`growth_rate` 返回 `(current-baseline)/baseline*100`，字段名 `growth_rate_pct`，已是百分数，不应再次乘 100。零基数返回 NULL 和原因，不返回 0%。计算使用 128 位有效数字上下文；无限循环小数在此精度处舍入，展示按指定小数位 ROUND_HALF_UP。

成功计算返回独立 `aggregate-N` ID、输入结果 ID 和公式/操作。可继续计算或通过 `read_query_result` 分页读取；分页引用坐标始终按原结果的零基行号，不是当前页行号。跨会话复用时只恢复版本匹配的 SQL 证据，计算可据此重新执行，不信任模型历史文案中的数值。

## 发布引用

模型输出模板示例：

```text
2021年总额{{aggregate-1:0:amount|4}}万元；
差额{{aggregate-2:0:difference|4}}万元；
增长率{{aggregate-3:0:growth_rate_pct|2}}%。
```

格式为 `{{结果ID:原结果零基行号:唯一列名|可选小数位}}`，小数位允许 0–12。服务器校验 ID、行列范围、截断状态、计算列类型和请求要求的汇总/差额/增长率引用，然后替换为工具值。普通文本单元格也可引用，如电缆规格 `1*35`，不允许设置小数位，HTML 中按文本转义。

门禁覆盖定量文本回答和 HTML 可见数值。未引用的字面量（含中文数词）、把原始单元格当计算值、缺少请求所需的计算类型、未知/越界引用均不能作为成功答案发布。允许明确的年份标签、列表序号、授权文件/表标识及 `mm2` 等单位文字，不能将任意相等数字视作有效引用。HTML 样式中的字号、颜色等不是业务指标；这不是图表属性数值的通用审计器。

范围标签如“13个区域”必须对应当前实际 SQL 引用的授权表数，不按业务记录数放行。NULL 不等于零的注释、引用中已声明的小数位说明，以及原始文本单元格中存在相同乘数模式的符号规格说明，按非指标文字处理；未验证的数字规格/范围不放行。纯数字文件名不能成为任意相同数值的白名单。紧邻“差额/增长率/总额”等明确标签的引用还需匹配对应计算类型，避免交换引用坐标。

正常路径直接分块输出经过校验的模板，不再调用模型重写数字。如果非定量草稿触发最终润色，先缓冲并检查润色结果，再输出，不允许未经核验的数字先流给客户端。失败最多纠正两次，第三次返回 `numeric_evidence_invalid`；报告失败沿用工具循环防护，不保存不合格 HTML。

`numeric.validated` SSE 事件及会话工具记录保留结果 ID、坐标、填入值、来源快照/输入结果 ID，可从该轮查询/汇总记录追溯。默认日志只记录校验次数与原因类别，不输出回答全文或数值。诊断事件可以提示具体未引用字面量，以便模型修正。

## 边界

这是确定性的“计算值与引用”约束，不是通用的自然语言语义证明：不能保证模型选对业务字段、过滤条件、单位、分组或年份口径；也不能证明用户要求的全部业务维度都覆盖。SQL 计算列识别采用保守的直接投影规则，复杂 CTE 外层仅投影别名时可能要求再次用受控汇总工具计算。SQL 自身的 REAL 求和仍遵循 SQLite 浮点语义；十进制工具不会恢复已在输入处损失的精度。业务黄金集、来源审计和报告人工验收仍需要保留。
